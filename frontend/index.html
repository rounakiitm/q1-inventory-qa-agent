About

        

          
Inventory Intelligence is an agentic Q&A layer over an Excel inventory:
          it writes and executes sandboxed pandas code, looks up external context via
          grounded search, renders charts, and answers with cited numbers.

          
    
            
  • Sandboxed code execution (AST gate · 15 s timeout · no network)
    • 
            
  • User-selectable low-cost models (3.1-flash-lite · 3.5-flash-lite · 3.5-flash)
    • 
            
  • Supabase Auth + Postgres (prod) · SQLite fallback (local/dev)
    • 
            
  • SSE streaming: watch every tool call as it happens
    •
